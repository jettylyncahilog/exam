CHAT EVERYWHERE 2.2 – Tagalog & Bisaya support

Files:
- manifest.json
- background.js
- content.js
- style.css

Install in Chrome:
1. Extract the ZIP.
2. Open chrome://extensions
3. Remove the old Chat Everywhere (if installed).
4. Click Load unpacked → select the chat-everywhere-fixed folder.
5. Go to any normal website and hard refresh (Ctrl+Shift+R).

New in 2.2:
- Classmates understand and reply in the language you use:
  • English
  • Tagalog
  • Bisaya (Cebuano)
- When you drag a link and send it, they reply about the link.
- Typing indicator still shows while they are “thinking”.
- All messages are saved.

Try these:
- “hi” or “kamusta” or “kumusta”
- “need help with the project” / “kailangan ko ng tulong sa project” / “kinahanglan kog tabang sa project”
- Drag any link then press Send
- “salamat” / “thanks”

Tips:
- Fully remove the old extension before loading the new one.
- Test only on normal websites (not chrome:// pages).
